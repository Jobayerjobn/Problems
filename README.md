# 100 Probles of Backend Challenges

Welcome to my backend problem-solving journey! This repository is dedicated to solving 100 diverse backend engineering problems, ranging from basic API logic to advanced system design patterns.

## Objectives
- Master **Node.js** and **Express.js** core concepts.
- Implement production-grade **Error Handling** and **Security**.
- Deep dive into **Database Indexing**, **Aggregation**, and **Schema Design**.
- Practice writing clean, modular, and reusable code.

## Tech Stack
- **Runtime:** Node.js
- **Framework:** Express.js
- **Databases:** MongoDB (Mongoose) / PostgreSQL (Prisma)
- **Security:** JWT, Bcrypt, Helmet, Cors
- **Validation:** Zod / Joi
- **Logging:** Winston / Morgan

## Installation & Usage
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to a specific challenge:**
   ```bash
   cd 01-custom-error-handler
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Run the development server:**
   ```bash
   npm run dev
   ```
